# 🍞🥚 Toast & Egg – Java Platform Game

A dynamic 2D platform game written in **Java**, where you play as a brave slice of bread 🍞,
fighting enemies and trying to reach your ultimate goal — the egg 🥚.

## 🎮 About the Game

The player controls a bread character who travels through a map full of dangers, enemies, and bonuses.

### ✨ Game Mechanics
- 👻 Fighting ghosts
- 👊✨ Melee attack (punch)
- 🔥 Fireball attack
- 🕊️ Jumping and flying (long jump) by pressing the spacebar
- 🍅🥑 Collecting tomatoes and avocados to gain points
- ⏱️ Level completion time is tracked
- 🥚 **Goal of the game**: reach the egg at the end of the map

### 🎯 Controls

| Key | Action |
|-----|--------|
| `S` | 👊✨ Punch |
| `F` | 🔥 Fireball |
| `SPACE` | 🚀 Jump |
| ⬆️ + `SPACE` | 🕊️ Long jump / Fly |
| ⬅️⬆️➡️⬇️ | Move character |

## ▶️ How to Run the Project

### 1️⃣ Requirements
- ☕ **Java JDK** (e.g. Java 17)
- 🧠 **IntelliJ IDEA** (recommended)

### 2️⃣ Project Setup
1. Open the project in **IntelliJ IDEA**
2. Set the JDK: File → Project Structure → Project SDK → Java (e.g. 17)
3. Make sure the following folder: src/main/java is marked as **Sources Root**

### 3️⃣ Running the Game
1. Navigate to: src/main/java/org/example/Main
2. Open the **GameFrame** class
3. Click **Run**
4. The game will start in a new window 🎉
